# 🌿 Hinglaj Farsan — Restaurant Website

A premium, fully responsive static landing page for **Shree Hinglaj Farsan Mart** — an authentic Indian street food restaurant with 35+ years of tradition.

## 🚀 Live Demo
> Hosted via [GitHub Pages](https://pages.github.com/) — see the live URL once deployed.

## 📁 Project Structure
```
hinglajfarsan/
├── index.html       # Main HTML (single page, 7 sections)
├── style.css        # All styles (CSS variables, Flexbox/Grid, animations)
├── README.md
└── images/          # All food & restaurant images
    ├── Mix_Chavanu.jpg
    ├── Samosa.jpg
    ├── Mohanthal.jpg
    └── ...
```

## ✨ Features
- **Pure HTML + CSS** — no JavaScript, no frameworks
- **Fully responsive** — mobile, tablet, desktop
- **7 sections**: Navbar, Hero, About, Menu, Marquee, Featured Dishes, Visit Us, Footer
- **CSS animations**: marquee strip, scroll indicator, hover effects
- **Inline SVGs** — no icon CDN dependency, works fully offline
- **Google Maps embed** — pinned to exact location
- **Google Fonts**: Cormorant Garamond (serif) + Inter (sans-serif)
- **Clickable phone link** (`tel:`) for mobile users

## 🌐 Deploy to GitHub Pages
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, root `/`
4. Your site will be live at `https://<username>.github.io/<repo-name>/`
